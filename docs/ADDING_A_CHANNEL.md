# Adding a channel
Copy a small channel (e.g. `openjames/channels/discord.py`), set `name`, `env_keys`, `help` (where to get credentials) and `id_hint`, and implement `poll()` (new inbound messages, skip history on first poll) and `send(to, text)`. Optional: `check()` for a live credential test in `doctor`, `discover_sender()` for zero-typing setup, `bind(allowed)` if you must know the principal. Use `channels/_http.call` for HTTP. Add the name to `CHANNELS` in `config.py` and a fake-transport test in `tests/test_channels.py`. Prefer polling over webhooks so no public URL is needed.
